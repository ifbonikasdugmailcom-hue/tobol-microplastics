Геоэкологический портал проекта **«Капиллярный интернет Тобола»**, получающий информацию от автономных станций мониторинга и отображающий динамику загрязнения микропластиком бассейна реки Тобол протяженностью 1591 км.

---

## 🌊 Ключевые возможности системы

### 1. Интерактивная векторная карта и 3D-карточки станций Тобола
- **5 опорных станций мониторинга:**
  - **Т-01:** Верхний Тобол (приграничный створ, фоновый уровень);
  - **Т-02:** Средний Тобол (Костанайский рубеж);
  - **Т-03:** Курганский промышленный створ (критический скачок 24 част./м³);
  - **Т-04:** Ялуторовский створ (приток реки Исеть, 31 част./м³);
  - **Т-05:** Нижний Тобол (устьевой створ, г. Тобольск).
- При нажатии на станцию выводится полная телеметрия: дата и время анализа, количество обнаруженных частиц (част./м³), диапазон размеров (мм), тип пластика (ПЭТ, полиэтилен, полистирол), гидродинамика и экологический статус.
- 3D-параллакс карточки станций и живые волновые индикаторы потока.

### 2. Раздел новостей, научных статей и образования
- **Новости проекта:** экспедиции, калибровка оптических ячеек, запуск новых сенсоров;
- **Научные статьи:** результаты Рамановской микроспектроскопии, кинетика седиментации полимеров;
- **Образовательные материалы:** памятки для жителей бассейна Тобола, влияние микрочастиц на ихтиофауну;
- **Форма публикации:** удобный редактор с тегами, привязкой к станциям и поддержкой ИИ-черновиков.

### 3. Автономный экологический агент «Тобол-ИИ»
- Встроенный ИИ-ассистент, обученный на гидрологических и спектрометрических данных реки Тобол;
- Экспертный анализ причин резких скачков (створы Т-03 и Т-04);
- Генерация черновиков научных статей и пресс-релизов в один клик.

## 🚀 Быстрый старт

### Требования
- Node.js 18+
- npm или yarn

### Установка зависимостей
```bash
npm install
```

### Настройка переменных окружения
Создайте файл `.env.local` или укажите в конфигурации:
```env
# Gemini AI API Key (для ИИ-агента «Тобол-ИИ»)
GEMINI_API_KEY="ВАШ_КЛЮЧ_GEMINI"
```

### Запуск сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### Сборка для публикации
```bash
npm run build
```
